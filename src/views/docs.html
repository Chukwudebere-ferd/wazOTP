wazOTP Integration Guide

How to test and use wazOTP in your project.

wazOTP connects a single WhatsApp account and uses it to programmatically send OTPs and custom notifications to your users. Here is exactly what it can do and how to test it right now.

Step 1: Open /dashboard to link your WhatsApp account and copy your API key.
Getting Started

Authentication

Every request you make to the wazOTP API requires your secret API key.
You can find this key in your Dashboard. It is blurred for security; hover over it to reveal or click the copy icon.
Pass it in the Authorization header as a Bearer token.
Authorization: Bearer sk_live_your_generated_key
Feature 1: Notifications

Send a WhatsApp Message

Capability: Instantly send any custom text message to any WhatsApp number in the world, directly from your linked account.
How to test: Open your terminal and run the curl command below, replacing the API key and phone number with your own.
curl -X POST http://localhost:3000/v1/messages/send \
  -H "Authorization: Bearer sk_live_YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "to": "+2348012345678",
    "message": "Hello from wazOTP! Your transaction of $50 was successful.",
    "event": "transaction_alert"
  }'
Feature 2: OTP Verification

Send a One-Time Password

Capability: Automatically generate and send a 6-digit OTP code to a user for phone verification or 2FA.
How to test: Send a POST request to the send endpoint. The user will receive the OTP instantly on WhatsApp.
curl -X POST http://localhost:3000/v1/otp/send \
  -H "Authorization: Bearer sk_live_YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "phone": "+2348012345678"
  }'
Feature 2: OTP Verification

Verify the OTP Code

Capability: Verify the code the user entered. wazOTP securely checks it against the database and enforces expiration times (default 10 mins).
How to test: Take the OTP code you received on WhatsApp and submit it to the verify endpoint.
curl -X POST http://localhost:3000/v1/otp/verify \
  -H "Authorization: Bearer sk_live_YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "phone": "+2348012345678",
    "code": "123456"
  }'
Dashboard APIs

Session Control (For UI)

The dashboard UI uses these endpoints internally to manage the WhatsApp connection via Baileys.
GET /v1/whatsapp/session/status Returns connection state (connected, qr_ready, etc.)
GET /v1/whatsapp/session/qr Returns the raw QR string for rendering.
POST /v1/whatsapp/session/connect Initializes a new connection to WhatsApp.
POST /v1/whatsapp/session/relink Clears old session data and generates a fresh QR.
